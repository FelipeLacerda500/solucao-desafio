# Passo a Passo para Executar o Projeto "solucao-desafio"

Nome Completo: **Felipe Lacerda Fernandes de Assis**

Para começar, execute o comando `sudo apt update` para atualizar os pacotes do sistema. Depois, instale o Chromium e o Chromedriver com o comando `sudo apt install -y chromium-browser chromium-chromedriver`. Em seguida, instale as dependências necessárias com o comando `sudo apt install -y libglib2.0-0 libnss3 libgconf-2-4 libfontconfig1 libx11-xcb1 libxcomposite1 libxcursor1 libxdamage1 libxrandr2 libxss1 libasound2 libatk1.0-0 libgtk-3-0`. Agora, clone o repositório do projeto "solucao-desafio" com o comando `git clone https://github.com/usuario/solucao-desafio.git` (substitua `usuario` pelo nome de usuário correto do GitHub). Após clonar, entre no diretório do repositório com o comando `cd solucao-desafio`. Se o projeto usar o `pip` para gerenciamento de dependências, instale as dependências com o comando `pip install -r requirements.txt`. Por fim, execute o script principal do projeto, por exemplo, com o comando `python main.py`. Verifique a saída do terminal para confirmar se o projeto está funcionando corretamente.

Se precisar de mais ajuda, consulte a documentação no repositório ou entre em contato com Felipe Lacerda Fernandes de Assis.
